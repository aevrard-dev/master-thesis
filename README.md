# Master's Thesis: Continuous Low-Thrust Propulsion & Guidance Laws in DOCKS

---
### Overview
This work covers the implementation of continuous propulsion strategies, variable-mass integration, elemental pointing
reference frames, and autonomous control laws (Autopilot and Rosette) within **DOCKS**.

### About DOCKS
**DOCKS** is an open-source software suite developed by **CENSUS** (the space pole at Paris Observatory / Observatoire de Paris) designed to streamline space mission profiling, system prototyping, and trajectory analysis. 

* **Official Project / Public Resources:** [CENSUS DOCKS Public Repository](https://gitlab.obspm.fr/public_docks)
